Прототипы для выбора визуального направления.  
**Ни один вариант не утверждён автоматически.** Production UI не изменён.

## Вариант A — Editorial Knowledge

**Ось:** чтение / типографика / воздух

### Концепция
Редакционный портал знаний: материал читается как качественная инструкция, а не как dashboard.

### Типографика
- Display: **Source Serif 4**
- UI/body: **Source Sans 3**
- Body ≈ 18px, leading 1.7, мера колонки ≈ 38rem
- Заголовки с отрицательным tracking, без «кричащих» весов

### Композиция
Широкие поля, одноколоночный ритм, мало конкурирующих зон.

### Навигация
Верхняя текстовая навигация, активный раздел — жёлтый underline. Мобильное меню раскрывается панелью.

### Карточки
Почти не используются: списки с правилами/разделителями вместо плиток.

### Поверхности
Белый фон, мягкий muted для callout, без теней, radius 0.

### Анимация
Минимальная: меню, появление результатов поиска, `:active` на кнопках. Reduced motion поддерживается.

### Сильные стороны
- Лучшее чтение длинных инструкций
- Спокойный корпоративный тон
- Меньше визуального шума

### Ограничения
- Хуже плотность больших каталогов
- Меньше «инструментальности» для power-users

### Подходит для
База знаний с упором на статьи и качество чтения.

## Вариант B — Structured Workspace

**Ось:** плотность / модульность / скорость сканирования

### Концепция
Рабочее пространство: каталог, поиск и инструменты рядом.

### Типографика
- Единый **IBM Plex Sans** (UI + display)
- Body ≈ 15px, leading 1.45, компактные подписи 12px

### Композиция
Боковая навигация + верхний search; сетка карточек; модульные панели.

### Навигация
Sidebar с inset-accent на активном пункте; на mobile — выезжающая панель (transform/opacity).

### Карточки
Компактные модули с border и лёгкой тенью; selected = усиленная рамка.

### Поверхности
Muted sidebar, белый контент, radius 6px, тонкие границы.

### Анимация
Быстрые UI-переходы панелей/фильтров; без декоративного motion.

### Сильные стороны
- Быстрый обзор большого объёма
- Удобно совмещать контент и админ-фрагмент
- Хорошая сканируемость

### Ограничения
- Меньше «воздуха» для длинного чтения
- Риск ощущения admin-dashboard при перегибе

### Подходит для
Портал с большим каталогом и частым поиском.

## Вариант C — Guided Learning

**Ось:** маршруты / прогресс / практические действия

### Концепция
Обучающий контур: заметный прогресс, пошаговые блоки, выразительный жёлтый акцент на welcome/CTA (тёмный текст на жёлтом).

### Типографика
- **Nunito Sans** (единый семейный стек)
- Body 16px, leading 1.55; display жирнее, дружелюбнее, но деловой

### Композиция
Hero-маршрут, path-cards по ролям, step-cards в статье, progress rail.

### Навигация
Pill-навигация; активный пункт заливается акцентом (тёмный текст).

### Карточки
Скруглённые path/step cards; статус через chip + точку + текст (не только цвет).

### Поверхности
Жёлтый hero/callout, тёмный video placeholder, мягкая тень.

### Анимация
Progress fill на replay; панели/фильтры; reduced motion → без transform-slide.

### Сильные стороны
- Ясные учебные маршруты
- Хорошо стыкует видео + шаги + практику
- Акцент помогает «продолжить»

### Ограничения
- Менее универсален как чистый справочник
- Жёлтый нужно дозировать, чтобы не уйти в игривость

### Подходит для
Онбординг, курсы, сценарии «сделай по шагам».

## UI-подход (pick-ui-library)

Для Phase 2A **внешняя UI-библиотека не требуется**:

- своя визуальная система на CSS tokens
- без Motion (достаточно CSS transform/opacity)
- без готового UI-kit (избегаем visual lock-in)

В Phase 2B/5 при появлении сложных меню/диалогов/DnD рассмотреть **base-ui** (headless) и **dnd kit** — отдельным решением/ADR.
